
# SHANANA Cargo Website

A collaborative frontend development project to recreate the layout and functionality of a logistics website.

## Reference Website
https://grandlacs-logistics.com/

## Team Branch Structure

- main: Stable production version.
- dev: Integration and testing branch.
- john-work: John's development branch.
- edison-work: Edison's development branch.
- member3-work: Third member's development branch.

## Development Workflow

1. Each team member works on their own branch.
2. Completed work is submitted to dev through Pull Requests.
3. The team tests and reviews changes in dev.
4. Approved and stable work is merged into main.
